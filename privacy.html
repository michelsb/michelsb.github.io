Informações do site

Política de Privacidade

Última atualização: 31 de outubro de 2026

Esta política explica como dados podem ser tratados durante o uso do site pessoal de Michel Sales Bonfim, disponível em michelsb.github.io.

Dados coletados por este site

Este site é informativo e estático. Ele não oferece formulários, contas de usuário, comentários ou inscrições e não utiliza intencionalmente ferramentas próprias de análise de audiência, publicidade ou rastreamento. O site não define cookies próprios para esses fins.

Serviços de terceiros

O site utiliza recursos hospedados por terceiros. A foto de perfil é carregada do GitHub e as fontes tipográficas são carregadas do Google Fonts. Ao abrir páginas que carregam esses recursos, seu navegador pode enviar a esses provedores dados técnicos, como endereço IP, informações do navegador e a página solicitada. O tratamento desses dados é regido pelas políticas dos respectivos provedores:

  • Declaração de Privacidade do GitHub
  • Política de Privacidade do Google

Os links para a UFC, Lattes, ORCID e repositórios do GitHub levam a sites externos. Ao acessá-los, você passa a estar sujeito às políticas e práticas de privacidade desses serviços.

Hospedagem

O site é publicado pelo GitHub Pages. A infraestrutura de hospedagem pode processar dados técnicos de acesso para operar, proteger e manter o serviço, de acordo com as políticas do GitHub. Este site não recebe acesso a registros internos da hospedagem.

Currículo Lattes

O currículo disponibilizado neste site é um arquivo PDF estático. Ao abri-lo ou baixá-lo, seu navegador solicita o arquivo à hospedagem do site, que pode processar os dados técnicos desse acesso conforme descrito acima.

Contato

Para dúvidas sobre esta política ou sobre o conteúdo deste site, utilize as informações de contato disponíveis no perfil institucional na UFC.
