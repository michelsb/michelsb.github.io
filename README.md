# Site pessoal de Michel Sales Bonfim

Site estático em HTML e CSS, sem dependências de build, pronto para publicação
no GitHub Pages.

## Publicar no GitHub Pages

1. Crie ou use o repositório `michelsb.github.io` na conta `michelsb`.
2. Envie para a raiz do repositório os arquivos `index.html`, `privacy.html`,
   `styles.css`, `lattes.pdf` e a pasta `en/`.
3. No GitHub, abra **Settings → Pages** e selecione **Deploy from a branch**,
   branch `main` e pasta `/(root)`.
4. Salve e aguarde a publicação em `https://michelsb.github.io`.

O currículo PDF já está na pasta e é ligado pelo botão “Currículo Lattes”.
Para atualizar as informações, edite o conteúdo do `index.html`; cores,
tipografia e layout ficam em `styles.css`.

A política de privacidade está em `privacy.html` e pode ser atualizada para
refletir mudanças nos recursos ou serviços utilizados pelo site.

A versão em inglês fica em `en/index.html`, e sua política de privacidade em
`en/privacy.html`. Os links de idioma no cabeçalho permitem alternar entre as
versões em português e inglês.
